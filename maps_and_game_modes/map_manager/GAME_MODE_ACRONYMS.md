# Game Mode Acronyms

*Maps in Monkanics are game mode specific. Meaning a Bean-aza map won't be used for another game mode. So, map file names have a game mode acronym prefix attached. Similar to games like Team Fortress 2.*

Development test maps have no acronyms.
