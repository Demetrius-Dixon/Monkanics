### About the Deprecated Folder

This utility folder is used to hold all outdated scripts/scenes/folders/etc *that should not be used EVER*. 

This was done to reduce clutter in Monkanics' filesystem, reference the scripts before deletion, and have a placeholder file to keep the deprecated folder in the repo.

**Deprecated files WILL be deleted before the in-development branch is merged into the main branch and WILL NOT be organized.**
