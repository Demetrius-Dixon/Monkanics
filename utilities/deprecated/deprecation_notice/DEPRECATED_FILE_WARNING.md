### About the Deprecated Folder

This utility folder is used to hold all outdated scripts/scenes/etc *that should not be used EVER*. 

This was done to reduce clutter in Monkanics' filesystem, reference the scripts before deletion, and have a placeholder file to keep the deprecated folder in the repo.

*Do not place folers in the deprecated folder!*

**Deprecated files (except the `DEPRECATED_FILE_WARNING`) WILL be deleted before the in-development branch is merged into the main branch and WILL NOT be organized.**
